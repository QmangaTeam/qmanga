# Frontend (SvelteKit) — Skeleton

This directory contains a minimal SvelteKit skeleton intended as a starting point.

To initialize fully, install dependencies and run the dev server:

```bash
cd frontend
pnpm install   # or npm install
pnpm dev       # or npm run dev
```
