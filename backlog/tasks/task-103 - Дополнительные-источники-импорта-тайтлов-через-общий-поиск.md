## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Продолжение запроса «Shikimori и других сайтов». Расширить тот же поиск адаптерами других каталогов; первоначальные кандидаты MangaDex и AniList. Перед реализацией подтвердить их актуальные документированные способы доступа/доступные поля и зафиксировать поддерживаемые источники в этой карточке, без обхода ограничений сайтов.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 В том же поиске можно выбрать поддерживаемый внешний источник; результаты и внешний ID не смешиваются, название/тип/изображение помогают выбрать правильный тайтл.
- [ ] #2 Как минимум один дополнительный источник помимо Shikimori работает через общий контракт заполнения метаданных и тегов, без отдельной несовместимой формы; недоступные поля остаются честно неизвестными.
- [ ] #3 Кеш/таймаут/лимиты, provenance, обновление с сохранением ручных правок и ошибки реализованы отдельно для каждого адаптера; отказ одного источника не блокирует остальные, есть source fixtures и browser поиск→выбор→импорт.
