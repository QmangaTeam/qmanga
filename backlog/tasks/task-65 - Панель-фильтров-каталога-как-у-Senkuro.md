## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Запрос владельца (20.10.2026): скопировать фильтры с senkuro.me/browse/manga — вёрстку для ПК и телефона и логику. Ответы владельца: (1) добавить все группы Senkuro, включая год, количество глав, формат, первоисточник и страну; (2) несколько тегов остаются с логикой AND; (3) фильтр применяется сразу по клику, кнопки «Применить» нет.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Панель фильтров повторяет структуру Senkuro: поиск по тегам, 6 групп тегов с «Популярные» и «Полностью» (подпанель со всеми тегами группы), затем тип, возраст, главы, год, формат, статусы, первоисточник, страна; на desktop — колонка справа, на телефоне — полноэкранная панель.
- [ ] #2 Фильтры применяются сразу по клику через URL, без кнопки «Применить»; сброс — иконкой в заголовке панели; состояние переживает перезагрузку и «назад».
- [ ] #3 Логика: теги — AND между собой; внутри групп типа, возраста, статусов, формата, первоисточника и страны — OR; между группами — AND. Диапазоны глав и года включительные.
- [ ] #4 API принимает повторяющиеся параметры и валидирует значения; старые одиночные параметры и пустые значения не ломают запрос.
- [ ] #5 Проверено: Go-набор с PostgreSQL, web-тесты и svelte-check, браузерная приёмка 320/360/desktop, kk/ru, обе темы; релиз того же SHA на production с внешней проверкой.
