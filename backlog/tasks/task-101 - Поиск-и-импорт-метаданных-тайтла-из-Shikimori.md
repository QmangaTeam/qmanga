## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Владелец: «пишешь в поиск выбираешь тайтл и он автоматом загружает метаданные имеющиеся». Первый источник — Shikimori. Выбор результата автоматически заполняет форму и теги через общую политику сопоставления; ручное переписывание каждого поля не требуется. Перед реализацией сверить действующий документированный API/лимиты источника.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 В форме создания/изменения тайтла есть поиск по Shikimori с различимыми результатами (названия/тип/год и обложка при наличии), loading/empty/error/retry; пользователь явно выбирает нужный тайтл.
- [ ] #2 После выбора автоматически заполняются доступные поддерживаемые названия, оригинал/алиасы, описание, авторы, тип/статусы, даты/публикация, изображения и теги; отсутствующие поля не выдумываются и не очищают уже введённые данные.
- [ ] #3 Источник, внешний ID и происхождение данных видимы; смена выбранного результата не теряет несохранённое без согласия, заполнение не публикует тайтл само по себе, существующие права/модерация/версии сохранены.
- [ ] #4 Импорт находится за application port/source adapter, имеет кеш/таймауты/лимиты и безопасную обработку URL/изображений; API fixtures и browser сценарий поиск→выбор→проверка→сохранение покрыты.
<!-- AC:END -->
