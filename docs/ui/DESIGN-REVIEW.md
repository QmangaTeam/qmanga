# Qmanga UI direction

Актуальные решения владельца, 18 октября 2026 года. Эти требования заменяют ранние планы редизайна и указания сохранять зелёный акцент.

## Палитра и композиция

- Палитра Senkuro: тёмный фон `#101014`, панель `#231A17`, оранжевый акцент `#FF873D`. Светлая тема — читаемый оранжево-коричневый вариант. Проверять контраст обеих тем.
- Компактная библиотека чтения: реальные обложки, короткие заголовки, понятные кнопки, плотные строки глав. Без рекламного hero, декоративных лозунгов и выдуманной статистики.
- Порядок главной и поведение полок описаны в [контракте компоновки](SENKURO-LAYOUT.md).
- Страница тайтла: обложка, действия и метаданные слева на desktop; компактная шапка на телефоне. По референсам владельца от 21 октября факты и расширенные метаданные объединены в одну панель: под действиями слева на desktop (от960px), под навигацией разделов на мобильных и планшетах; На мобильных и планшетах до960px — единая горизонтальная лента сведений с нативной прокруткой касанием/клавиатурой; desktop сохраняет одну колонку в sidebar. Сипаттама/Описание на всех ширинах имеет превью до3строк; локализованная кнопка раскрытия/сворачивания появляется только при фактическом переполнении этих3строк. Проверять rendered height после resize/font load, а не число слов. Все сведения сохранять без дублирования. По уточнению владельца авторы, издатели и команды — компактные подписанные chips вне контейнера горизонтальных фактов. В фактах нет дублирующего числа глав (оно остаётся во вкладке и статистике); подписи имеют иконки, статусы — цветную точку вместе с текстом. Команды показывают существующий аватар с fallback-иконкой. Scrollbar мобильной ленты скрыт, нативные swipe/trackpad/keyboard сохраняются; длинные aliases идут горизонтально без роста всей панели. Высота сведений и contributor-группы естественная до viewport-зависимого максимума, затем включается внутренняя прокрутка: не растягивать страницу и не добавлять пустую высоту короткому содержимому. Переключение разделов сохраняет scroll position; активный индикатор и содержимое имеют короткий sliding transition с отключением при reduced motion. Разделы «О тайтле / Главы / Комментарии / Статистика» с состоянием в URL. Не добавлять несуществующие коллекционные карточки.
- Первый пакет21октября (TASK-108–110, локальная приёмка): адаптивная главная с продолжением первым для вернувшегося читателя и без повторной нижней полки; мобильная шапка тайтла — обложка100px рядом с названием/оценкой, действия ниже, desktop banner максимум180px. Сохраняются действия, сведения и текущие цвета.
- Использовать только собственные или разрешённые изображения; не копировать арт, брендинг и приватные данные референса.

## Рабочие области: HTML-образец владельца от 2026-10-22

Студия использует утверждённый `qmanga-studio.html`: боковая панель 208 px, компактная полоса 72 px в редакторе, верхняя строка 64 px, плотный список проектов и нейтральные поверхности `#17171c`/`#1e1e24`. Изменения ограничены рабочими областями; публичная палитра сохраняется. Светлая тема поддерживается локальными семантическими токенами. Кнопки остаются не меньше 44 px даже там, где прототип использует 32–40 px.

Рабочая сетка показывает реальные thumbnail и состояние страницы. Выбор открывает существующие действия в инспекторе справа; на телефоне инспектор раскрывается перед сеткой, получает фокус и возвращает его выбранной плитке при закрытии. Точные версии, права, импорт CBZ/PDF, порядок, подтверждения и проверка перед отправкой сохраняются. Три раздела редактора переключают рабочую поверхность и на desktop; это новая структура из образца вместо прежнего одновременного отображения всех форм. Размер плитки не зависит от пропорций исходного изображения.

Пустые закрепления, выдуманные даты обновления и демонстрационные метрики из HTML не переносятся как продуктовые данные. Новые bulk/history/zoom-сценарии требуют отдельной реализации и серверного контракта. После экспорта Figma 22 октября админка использует образцы страницы «01 · Админ-панель»: боковая панель 224 px, верхняя строка 64 px, тёплая палитра Senkuro, плотные таблицы и список с инспектором. Рабочая очередь объединяет пять существующих очередей; счётчики обозначают загруженные данные и нижнюю границу при пагинации. Переход к материалу сохраняет глубину загрузки. Проверка публикации показывает manifest точной версии и отдельную панель решения; каталог начинается со списка, аккаунты, команды, заявки и обращения используют выбранную запись справа, журнал раскрывает подробности строки. Справочники переключают жанры, категории и подборки, сохраняя существующие операции импорта и редактирования. Все девять действующих маршрутов сохранены. Недоступные серверные сведения и демонстрационные метрики из макета не выдумываются; это адаптация к действующему API, а не подтверждение пиксельного совпадения всех 50 состояний экспорта.

## Типографика

Текущий шрифт интерфейса — локальный variable Onest (100–900), один WOFF2 без внешнего font-сервиса. Казахские и русские символы проверены в cmap; системный запасной шрифт и `font-display: swap` сохраняют чтение при ошибке или медленной загрузке. Не добавлять preload шрифта в ущерб первой странице манги. Лицензия SIL OFL 1.1 поставляется вместе с сайтом.

## Язык и взаимодействие

- По умолчанию Қазақша; Русский — явный запоминаемый выбор. Смена языка не переводит контент манги и не сбрасывает прогресс.
- Современные понятные подписи: Аккаунт, Профиль, Каталог, Кіру, Тіркелу, Оқу, Жалғастыру. Локализовать также ошибки, формы, даты, счётчики и доступные имена.
- Справа — следующая страница, слева — предыдущая, в том числе для RTL-манги. Обратное управление включается только вручную; вертикальная лента идёт сверху вниз.
- Вход/регистрация используют тот же single-Q wordmark, что и header. Мобильное меню: Каталог, Кітапхана/Сөре, центральный Home с Q-логотипом, Хабарлар, Мәзір; без дублирующего Home.
- Комментарии: аватар/имя/дата, компактные действия и ясное вложение ответов; inline reply/edit содержит контекст и закрытие, гибкий toolbar, предпросмотр и отправку. Существующие цвета, форматирование, spoiler/report/pagination и scope мутаций сохраняются.
- Первый вход в комментарии для вошедшего пользователя — компактная кнопка написания. Раскрытый редактор закрывается с сохранением корневого черновика; ошибка отправки сохраняет текст/спойлер. Загруженные ветки ответов можно свернуть без потери содержимого; ссылка на конкретный ответ автоматически раскрывает ветку. Inline reply/edit, пагинация и отдельные цели мутаций сохраняются.
- Редактор комментария — одна поверхность ввода: placeholder вместо повторяющихся видимых заголовков, доступный label сохраняется; контекст адресата показывается для ответа/редактирования. Панель форматирования, spoiler, preview и отправка остаются доступными на телефоне.
- Полная информация и участники тайтла показываются только во вкладке «О тайтле». Жанры/теги имеют ограниченное превью и «Подробнее/Свернуть» только при измеренном переполнении; скрытые ссылки исключены из порядка Tab. Горизонтальная metadata-лента сохраняет скрытую полосу прокрутки и показывает градиент на стороне оставшихся данных.
- Несколько переводов одной главы — одна компактная строка с числом версий. Native disclosure открывает ограниченный по высоте список; при более пяти версиях доступен поиск команды. Чтение всегда ведёт на точный release, профиль команды — отдельная ссылка. Номер тома остаётся в заголовке главы; новый прогресс не выдумывается.
- Сохранять пять основных мобильных направлений, рабочие сценарии и [архитектурные границы](../ARCHITECTURE.md).

## Проверка изменений

Сначала проверять переиспользуемые компоненты, затем собирать экраны. Использовать [design-product-ui](../../.agents/skills/design-product-ui/SKILL.md).

Проверять 320/360 px и desktop, обе темы, длинные казахские подписи, пустые/заполненные состояния и ошибки сети. Зоны действий — не менее 44 px; учитывать клавиатурный фокус, увеличение и reduced motion. Браузерная эмуляция не подтверждает производительность физического Android.
