# Сверка функционального MVP

Дата: 17 октября 2026. Исходная точка: `f04c1b1`. Сверены `QMANGA-PLAN.md`, `QMANGA-READER.md`, `QMANGA-ROADMAP.md` и последующие решения: Kazakh-first / Russian UI, Go media gateway, Clean Architecture / DDD, Alpine Docker. Продакшен исключён из задачи.

Предыдущая отметка редизайна не означала завершение всех функций первоначального плана. Ниже устранённые пробелы и отдельно оставшаяся приёмка. Зелёная сборка не равна публичному запуску.

## Поправка после проверки владельцем

Предыдущая сверка пропустила реальные разрывы кабинета: запрос проекта отсутствовал, логическую главу мог заранее создавать только администратор. Сценарий переводчика был переоценён. Теперь добавлены заявки на проекты/новые тайтлы, решения и история, возврат/повторная отправка заявки команды, создание глав редактором и единое меню. Сквозной путь вручную пройден от заявки до опубликованной синтетической тестовой главы. Точный состав и проверки: [STUDIO-WORKFLOW-VALIDATION.md](ui/STUDIO-WORKFLOW-VALIDATION.md).

## Что отсутствовало и сделано

| Пункт плана | Реализация |
| --- | --- |
| Новые переводы и подборка | Лента опубликованных релизов `/updates`, курсор, фильтр команды; главная показывает главы, не выдаёт обновлённые карточки за новые главы. Редакционная подборка задаётся администратором явно. |
| Метаданные каталога | Авторы, сортировка новых произведений, фильтр наличия глав. Администратор может открыть карточку-анонс без глав; обычный черновик закрыт. Обсуждение и обращение по правам доступны и для анонса. |
| Профиль и команды | Редактируемое публичное имя; публичный состав команды без почт, ссылки на последние релизы. Почта участников доступна только уполномоченному управлению командой. |
| Возврат после входа | Безопасный локальный `returnTo`, сохранение перехода между входом/регистрацией/восстановлением. Из комментариев возврат на тот же тайтл. Внешние и служебные адреса запрещены. |
| Уведомления | Решения publish/reject/withdraw для действующих участников команды через transactional outbox. Без предпочитаемой команды — одно уведомление о логической главе независимо от дублей перевода. Загруженные новые главы группируются по тайтлу; ответы и решения не смешиваются. |
| Библиотека при обрыве | Версии выбора статуса, избранного, команды, уведомлений; очередь IndexedDB, ожидание/повтор и явное разрешение конфликта. Удаление — версионированный tombstone: старое событие не восстанавливает запись молча. |
| Гонки вкладок | Сохраняется версия, которую видел пользователь. Локальный changeId и атомарный compare-and-swap не позволяют старому ответу стереть новую очередь. В хранилище идут только поля выбора, не реактивная модель UI. |
| Кеш просмотренного | Отдельный LRU публичных изображений с бюджетом 50 MiB. Приватные preview, HTML, частичные/неполные и слишком большие ответы не записываются. Явные скачивания в другом кеше не затрагиваются LRU. При сети — проверка через Go; отказ доступа/404/410 очищает соответствующий объект управляемых кешей. |
| Источник и права | Версионированные источник/кредиты ревизии, видимые в manifest/читалке. Подтверждение права размещения требуется до submit и publish. Это запись заявления участника, не доказательство юридических прав. |
| Порядок страниц | Номер позиции и кнопки перемещения. Перестановки/удаления сначала локальные, затем сохранение либо отмена. Применение атомарно по исходной версии; недопустимый список откатывает удаление, jobs удалённых страниц отменяются. |
| Обращения | `/rights` без регистрации: закрытые контакт/текст, ограничение частоты, секретная квитанция с хешем в БД, проверка результата без токена в URL. Почта не считается подтверждённой. `/reports` — собственные обращения и результаты модерации. |
| Аккаунты и аудит | Администратор меняет роли/блокировку; модератор блокирует только читателей. Нельзя менять себя или убрать последнего активного администратора. Версии, отзыв сессий, журнал причин. Заблокированные оценки исключены из агрегатов. |
| Рабочие списки | Подгрузка по 100: админ-каталог, выбор одобренной команды, проекты, главы/ревизии studio, очереди релизов/команд, собственные команды и участники. Публичный каталог/главы и личные списки имеют свои курсоры. |

Миграции 9–15 добавляют поля/индексы без очистки данных. Старый материал не получает выдуманного подтверждения прав; неподтверждённую заявку следует вернуть команде.

## 13 критериев первоначального плана

| № | Программная часть | Оставшаяся приёмка |
| --- | --- | --- |
| 1 | Гостевой поиск по казахским/альтернативным названиям и чтение. | Реальный каталог и читатели. |
| 2 | Предпочтение команды; нет автоматической подмены перевода. | Полевой сценарий двух команд. |
| 3 | Локальная позиция, повтор, ограниченное окно, кеш просмотренного. | Длительный обрыв и переключение приложений на телефоне. |
| 4 | Реальные WebP eco/standard/high, проверка MIME/размеров/хешей. | Читаемость казахского текста на настоящем материале. |
| 5 | Окно декодирования с ориентиром 40 MiB и освобождением ресурсов. | Слабый физический Android, длинный вебтун, память процесса. |
| 6 | Явная загрузка главы, целостность/квота, офлайн-читалка, удаление копии. | Перезапуск физического браузера, eviction и обновления service worker. |
| 7 | Версии/повторы/конфликты прогресса, теперь и очередь выбора библиотеки. | Два реальных устройства. |
| 8 | Изоляция команд и независимые переводы в PostgreSQL-тестах. | Две реальные команды проходят путь без разработчика. |
| 9 | Загрузка, обработка, порядок/отмена, preview, возврат/публикация в UI. | Полный мобильный процесс редактора на устройстве. |
| 10 | Закрытые manifest/media, атомарная активная ревизия, снятие. | Публичный выпуск в этой задаче не выполнялся. |
| 11 | Комментарии/ответы/спойлеры/оценки/жалобы с правами и защитой от дублей. | Живая модераторская приёмка. |
| 12 | KK по умолчанию, RU-переключение, локализованные состояния/ошибки/письма. | Полная вычитка носителем; код не удостоверяет качество языка. |
| 13 | Публикационный путь и локальные тестовые материалы. | Несколько действительно разрешённых произведений. Тестовая манга не считается разрешением на распространение. |

## Проверки этой итерации

- Полный Go/PostgreSQL/codec набор: `go test ./... -count=1`, изолированные схемы тестовой БД.
- Регрессии: публикация без прав; rollback ошибочного порядка; удаление с конфликтом версии и отменой jobs; команды/участники после первых 100 записей; анонс против закрытого черновика; приватность квитанции и результат обращения.
- Frontend: 38 tests / 183 assertions и 13 UI tests / 578 assertions, без падений; Svelte — 0 ошибок/предупреждений. Архитектурные границы, контраст обеих тем, preview-check, Docker build проходят. Локальные web/api/worker healthy.
- Независимый review выявил четыре дефекта: подмена базовой версии выбора, старый ответ поверх новой очереди, недоступное обсуждение анонса, неверный возврат из комментариев. Исправлены с регрессиями.
- Браузер дополнительно выявил DataCloneError при повторном сохранении реактивной записи. Воспроизведён тестом и исправлен на границе application/storage.
- Локальный браузер: анонимное тестовое обращение и статус квитанции; вход возвращает на `/admin/audit`; поиск тестового читателя без изменения его прав. Форма обращения и управление аккаунтами — 360 px, русская форма — 320 px, без горизонтального переполнения.
- После исправления браузерная проверка 320 px: отключена сеть, статус библиотеки изменён на «На паузе», показано одно ожидающее локальное изменение. После восстановления сети очередь исчезла; перезагрузка подтвердила серверный статус paused. Созданная тестовая запись затем убрана из библиотеки.
- В читалке high: страницы 1–4 просмотрены онлайн, возврат 4→3→2→1 выполнен с отключённой сетью; первая картинка декодирована (1190×1682). Сеть, обычное качество, KK и размер окна восстановлены; тестовая админ-сессия завершена. Это desktop-эмуляция, не физический Android.
- Скриншоты без страниц манги/квитанций: соседняя папка `outputs/ui-review`, файлы `mvp-library-offline-320.png` и `mvp-rights-kk-360.png` (вне Git).
- Тестовая манга, пароли, квитанции, cookies и личные данные не включены в Git.

## Открытые ограничения и границы

- Это функциональная локальная версия для закрытой приёмки, не заявление о выполнении всех 13 условий публичного запуска.
- Для первоначального открытия личной библиотеки нужна свежая авторизация; офлайн-изменения работают на уже открытой странице с установленным аккаунтом. Выход/смена аккаунта очищает локальные очереди. Сохранённые публичные главы не требуют авторизации.
- Кеш фрагментов не гарантирует полную главу: для этого есть явное скачивание. 50 MiB относится к runtime-кешу приложения, не ко всему диску браузера. Запрет CacheStorage не блокирует сетевое чтение. Отключённую копию невозможно отозвать дистанционно.
- Группировка уведомлений охватывает загруженные порции. Публичная карточка команды ограничивает состав 200 участниками и встроенные проекты 100; полный каталог/лента и внутренние рабочие списки доступны отдельно. Слабый телефон не загружает всё разом.
- `/saved` реализует скачанные главы, `/settings` — минимальный профиль; отличие URL от ранней схемы не означает отсутствие сценария.
- P1/P2 не добавлялись: провайдеры входа, импорт с чужих сайтов, отдельная подписка на команду, архивы, личные сообщения, достижения, платежи.
- Реальное устройство, языковая вычитка, разрешённый каталог и бета с людьми ещё нужны. TLS, домен, хостинг, внешняя почта, резервирование и развёртывание продакшена намеренно не менялись.
