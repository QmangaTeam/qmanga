## Незакрытые проблемы текущего пакета

1. **Applied filter против draft input.** Library.svelte и Projects.svelte при «Ещё» читают текущее несохранённое значение поиска, но используют cursor предыдущей выдачи. Изменить строку без submit → нажать «Ещё» может смешать наборы или пропустить совпадения. Нужно хранить применённые criteria отдельно от draft и привязать cursor к ним.
2. **Фильтр и total после изменения записи.** Library.svelte сохраняет статус/избранное и обновляет строку, но не пересчитывает состав отфильтрованной страницы/total. Ушедшая из выбранного списка запись остаётся видимой; pending/offline изменение может сохранить старое достоверно выглядящее число. Нужны requery/invalidation и честное partial состояние.
3. **Браузерный регрессионный тест не прошёл.** Сценарий библиотеки/проектов зависает на `getByLabel('Список', { exact: true }).selectOption(...)`. Причина ещё не установлена. Нельзя объявлять это ни исправленным продуктовым дефектом, ни безобидной нестабильностью теста. Часть с фильтром проектов в этом сценарии не была достигнута.
4. Browser bulk seeder не идемпотентен: повторный запуск в той же owner fixture добавит ещё 110 записей и сломает ожидание total=110. Для повторной приёмки нужна новая изолированная smoke fixture/учётная запись либо явное исправление seeder. Не очищать пользовательские volumes ради теста.
