# Frontend UI work

Before creating or revising visual presentation, read `../../.agents/skills/design-product-ui/SKILL.md` and apply the current Qmanga brief in `../../docs/ui/DESIGN-REVIEW.md`. Respect whether a direction is proposed or approved; do not treat a proposal as approval.

Preserve the Clean Architecture / DDD boundaries in `../../docs/ARCHITECTURE.md`. Styling is not permission to move HTTP, storage or business rules into Svelte components.

Mobile first: functional at320px, principal review at360px, interactive targets at least44px. Check long Kazakh labels, both themes and reduced motion. Do not report emulation as a physical Android test.
